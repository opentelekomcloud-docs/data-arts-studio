How Can I Create an Atomic Metric Using a Dimension Table Since Only a Fact Table Can Be Selected for Creating an Atomic Metric?
================================================================================================================================

In the standard data governance model, fact tables contain dimensions from dimension tables. During the creation of an atomic metric, the atomic metric is associated with a dimension table through the attributes in the dimension table.

If you want to create an atomic metric based on dimensions, you need to create a fact table using a dimension table and associate the atomic metric with the dimension attributes in the fact table.
