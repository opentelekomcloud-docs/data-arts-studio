Synchronizing APIs
==================

Operation Scenario
------------------

You can synchronize APIs from DataArts DataService Exclusive to Data Map.

Prerequisites
-------------

An API has been created.

.. _dataartsstudio_01_0321__section1089845413243:

Synchronizing APIs to Data Map
------------------------------

#. On the DataArts Studio console, locate a workspace and click **DataArts DataService**.

#. In the left navigation pane, choose an edition, for example **DataArts DataService Exclusive**, to access the **Overview** page.

#. Choose **API Development** > **APIs**.

#. Select the target APIs, click **More** above the API list, and select **Synchronize to Data Maps**.


   .. figure:: /_static/images/en-us_image_0000002269197833.png
      :alt: **Figure 1** Synchronize to Data Maps

      **Figure 1** Synchronize to Data Maps

#. On the **Synch Result** page, check the API synchronization status and details.


   .. figure:: /_static/images/en-us_image_0000002269197853.png
      :alt: **Figure 2** Synchronization result

      **Figure 2** Synchronization result

   .. note::

      -  Only published APIs can be synchronized to Data Map.
      -  Only APIs of the following data sources can be synchronized: DLI, DWS, HBase, and ClickHouse.
