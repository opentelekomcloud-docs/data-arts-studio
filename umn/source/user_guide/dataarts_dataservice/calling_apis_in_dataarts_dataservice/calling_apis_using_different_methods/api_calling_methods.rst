API Calling Methods
===================

Three authentication modes are available during API creation. The method for calling APIs varies depending on the API authentication mode. For details, see :ref:`Table 1 <dataartsstudio_01_0309__table1196445593713>`.

.. _dataartsstudio_01_0309__table1196445593713:

.. table:: **Table 1** API authentication modes and calling methods

   | (Recommended) App authentication | High           | After an API is authorized to an app, the key pair (AppKey and AppSecret) of the app is used for security authentication.                     | -  (Recommended) SDKs for multiple languages such as Java, Go, Python, JavaScript, C#, PHP, C++, C and Android                                                                                                                                          | -  :ref:`(Recommended) Using an SDK to Call an API Which Uses App Authentication <dataartsstudio_01_0355>` | App authentication and SDKs are recommended, which can help you easily and quickly obtain open data through data APIs.                                                                                                          |
   |                                  |                |                                                                                                                                               | -  API tool: You must manually generate a signature using **demo.html** in the JavaScript SDK package so that the API tool can be used to call APIs.                                                                                                    | -  :ref:`Using an API Tool to Call an API Which Uses App Authentication <dataartsstudio_01_0356>`          |                                                                                                                                                                                                                                 |
