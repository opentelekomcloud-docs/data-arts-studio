Searching for a Composite Metric
================================

Function
--------

Search for compound metric information by name, creator, reviewer, status, modification time, and l3Id.

Calling Method
--------------

For details, see :ref:`Calling APIs <making_request>`.

URI
---

GET /v2/{project_id}/design/compound-metrics
