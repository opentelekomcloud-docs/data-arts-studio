Creating Summary Tables
=======================

Function
--------

Manually create a summary table based on the input parameters.

Calling Method
--------------

For details, see :ref:`Calling APIs <making_request>`.

URI
---

POST /v2/{project_id}/design/aggregation-logic-tables
