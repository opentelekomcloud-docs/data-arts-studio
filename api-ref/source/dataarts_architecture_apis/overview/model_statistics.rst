Model Statistics
================

Function
--------

Statistics in a single model.

Calling Method
--------------

For details, see :ref:`Calling APIs <making_request>`.

URI
---

GET /v2/{project_id}/design/table-models/statistic

   +------------+-----------+--------+-------------------------------------------------------------------------------------------------------------------------+

.. table:: **Table 2** Query Parameters

   +-----------+-----------+--------+---------------------------------------------------------------------------------------+
   | Parameter | Mandatory | Type   | Description                                                                           |
