Creating a Model Workspace
==========================

Function
--------

--------------

Example Requests
----------------

Create a model workspace.

.. code-block:: text

   POST https://{endpoint}/v2/{project_id}/design/workspaces

   {
     "name" : "test_create_model",
     "table_model_prefix" : "",
     "description" : "this is a demo.",
     "type" : "THIRD_NF",
     "frequent" : false,
     "is_physical" : "true",
     "dw_type" : "DWS"
   }
