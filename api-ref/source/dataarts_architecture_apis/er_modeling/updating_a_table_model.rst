Updating a Table Model
======================

Function
--------

Updates a table model and its attributes, including logical entities and physical tables, in relational modeling.

Calling Method
--------------

For details, see :ref:`Calling APIs <making_request>`.

URI
---

PUT /v2/{project_id}/design/table-model
