Viewing Details About a Model
=============================

Function
--------

This API is used to query the workspace details of a physical or logical model.

Calling Method
--------------

For details, see :ref:`Calling APIs <making_request>`.

URI
---

GET /v2/{project_id}/design/workspaces/{model_id}

.. table:: **Table 1** Path Parameters

   +------------+-----------+--------+-------------------------------------------------------------------------------------------------------------------------------------------------------+
   | Parameter  | Mandatory | Type   | Description                                                                                                                                           |
   +============+===========+========+=======================================================================================================================================================+
   | project_id | Yes       | String | Project ID. For details about how to obtain the project ID, see :ref:`Project ID and Account ID <projectid_accountid>`.                               |
   +------------+-----------+--------+-------------------------------------------------------------------------------------------------------------------------------------------------------+
   | model_id   | Yes       | String | ID of the relational model, which is a string. The value of **model_id** can be obtained from the API used to :ref:`obtain a model <listworkspaces>`. |
   +------------+-----------+--------+-------------------------------------------------------------------------------------------------------------------------------------------------------+
