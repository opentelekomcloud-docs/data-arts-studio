.. _UpdateDesignTableQuality:

Update the abnormal data output configuration of the table.
===========================================================

Function
--------

Update the abnormal data output configuration of the table, including whether to generate abnormal data, setting the abnormal data database or schema, and setting the prefix or suffix of the abnormal table.

Calling Method
--------------

For details, see :ref:`Calling APIs <making_request>`.

URI
---

PUT /v2/{project_id}/design/{table_id}/qualities

   | table_id   | Yes       | String | Table ID, which is a string                                                                                             |
