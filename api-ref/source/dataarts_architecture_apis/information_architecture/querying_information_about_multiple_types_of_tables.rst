Querying Information About Multiple Types of Tables
===================================================

Function
--------

Query information about multiple types of tables from the information architecture, including logical entities, physical tables, dimension tables, fact tables, and summary tables.

Calling Method
--------------

For details, see :ref:`Calling APIs <making_request>`.

---
