View Dimension Granularity
==========================

Function
--------

This API is used to query the dimension granularity. All dimensions are queried based on tableId. If tableId is not transferred, the granularity of all dimension groups is queried.

Calling Method
--------------

For details, see :ref:`Calling APIs <making_request>`.

URI
---

GET /v2/{project_id}/design/dimension/groups
