Application Processing
======================

Function
--------

Reject/Approve one or more action-id=reject/resolve.

Calling Method
--------------

For details, see :ref:`Calling APIs <making_request>`.

URI
---

PUT /v2/{project_id}/design/approvals/action

.. table:: **Table 1** Path Parameters

   +------------+-----------+--------+-------------------------------------------------------------------------------------------------------------------------+
   | Parameter  | Mandatory | Type   | Description                                                                                                             |
   +============+===========+========+=========================================================================================================================+
   | project_id | Yes       | String | Project ID. For details about how to obtain the project ID, see :ref:`Project ID and Account ID <projectid_accountid>`. |
   +------------+-----------+--------+-------------------------------------------------------------------------------------------------------------------------+

.. table:: **Table 2** Query Parameters

   +-----------------+-----------------+-----------------+-------------------------------------+
   | Parameter       | Mandatory       | Type            | Description                         |
   +=================+=================+=================+=====================================+
   | action-id       | Yes             | String          | Application processing result type. |
   |                 |                 |                 |                                     |
   |                 |                 |                 | Options:                            |
   |                 |                 |                 |                                     |
   |                 |                 |                 | -  reject: rejected                 |
   |                 |                 |                 |                                     |
   |                 |                 |                 | -  resolve: approved                |

Example Requests
----------------

Approve the physical table release.

.. code-block:: text

   {
     "ids" : [ "1214980984198561792" ],
     "msg" : "Agree!"
   }
