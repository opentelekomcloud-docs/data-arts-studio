Searching for a Topic List
==========================

Function
--------

Search for topics by name (fuzzy query is supported), creator, owner, status, and modification time.

Calling Method
--------------

For details, see :ref:`Calling APIs <making_request>`.

---

Example Requests
----------------

Query the list of themes whose status is Draft and whose names contain abc.

.. code-block:: text

   GET https://{endpoint}/v2/{project_id}/design/subjects?name=abc&parent_id=-1&status=DRAFT
