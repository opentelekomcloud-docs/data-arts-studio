Obtains all directories.
========================

Function
--------

Obtains all directories (data standards and code tables).

Calling Method
--------------

For details, see :ref:`Calling APIs <making_request>`.

URI
---

Example Requests
----------------

Obtains all directories of the data standard based on the directory type.

.. code-block:: text

   GET https://{endpoint}/v2/{project_id}/design/directorys?type=STANDARD_ELEMENT
