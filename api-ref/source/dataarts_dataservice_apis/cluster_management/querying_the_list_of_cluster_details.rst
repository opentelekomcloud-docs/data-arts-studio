Querying the List of Cluster Details
====================================

Function
--------

This API is used to query the list of cluster details.

Calling Method
--------------

For details, see :ref:`Calling APIs <making_request>`.

URI
---

GET /v1/{project_id}/service/instances

.. table:: **Table 1** Path Parameters

   +------------+-----------+--------+-------------------------------------------------------------------------------------------------------------------------+
   | Parameter  | Mandatory | Type   | Description                                                                                                             |
   +============+===========+========+=========================================================================================================================+
   | project_id | Yes       | String | Project ID. For details about how to obtain the project ID, see :ref:`Project ID and Account ID <projectid_accountid>`. |
   +------------+-----------+--------+-------------------------------------------------------------------------------------------------------------------------+

.. table:: **Table 2** Query Parameters

   +-------------+-----------+---------+----------------------------------------------------+
   | Parameter   | Mandatory | Type    | Description                                        |
   +=============+===========+=========+====================================================+
   | limit       | No        | Integer | Maximum number of records that can be queried.     |
   +-------------+-----------+---------+----------------------------------------------------+
   | offset      | No        | Integer | Start coordinate of the query.                     |
   +-------------+-----------+---------+----------------------------------------------------+
   | name        | No        | String  | Cluster name. This parameter supports fuzzy match. |
   +-------------+-----------+---------+----------------------------------------------------+
   | create_user | No        | String  | Creator name.                                      |
   +-------------+-----------+---------+----------------------------------------------------+
