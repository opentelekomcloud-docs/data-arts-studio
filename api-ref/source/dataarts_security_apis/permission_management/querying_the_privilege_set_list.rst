Querying the Privilege Set List
===============================

Function
--------

This API is used to query the permission set list.

Calling Method
--------------

For details, see :ref:`Calling APIs <making_request>`.

URI
---

GET /v1/{project_id}/security/permission-sets

.. table:: **Table 1** Path Parameters

   +------------+-----------+--------+-------------------------------------------------------------------------------------------------------------------------+
   | Parameter  | Mandatory | Type   | Description                                                                                                             |
   +============+===========+========+=========================================================================================================================+
   | project_id | Yes       | String | Project ID. For details about how to obtain the project ID, see :ref:`Project ID and Account ID <projectid_accountid>`. |
   +------------+-----------+--------+-------------------------------------------------------------------------------------------------------------------------+

.. table:: **Table 2** Query Parameters

   +-----------------+-----------------+-----------------+--------------------------------------------------------------------------------------------------------------------------+
   | Parameter       | Mandatory       | Type            | Description                                                                                                              |

   | limit           | No              | Integer         | Number of items displayed on each page                                                                                   |

   | offset          | No              | Integer         | Offset, which is the position where the query starts. The value must be greater than or equal to 0.                      |

   | order_by        | No              | String          | Sorting parameter. The options are NAME, CREATE_TIME, and UPDATE_TIME.                                                   |
