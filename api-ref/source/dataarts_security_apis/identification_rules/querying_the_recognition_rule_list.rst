Querying the Recognition Rule List
==================================

Function
--------

This API is used to query the recognition rule list.

Calling Method
--------------

For details, see :ref:`Calling APIs <making_request>`.

URI
---

GET /v1/{project_id}/security/data-classification/rule

.. table:: **Table 1** Path Parameters

   +------------+-----------+--------+-------------------------------------------------------------------------------------------------------------------------+
   | Parameter  | Mandatory | Type   | Description                                                                                                             |
   +============+===========+========+=========================================================================================================================+
   | project_id | Yes       | String | Project ID. For details about how to obtain the project ID, see :ref:`Project ID and Account ID <projectid_accountid>`. |
   +------------+-----------+--------+-------------------------------------------------------------------------------------------------------------------------+

.. table:: **Table 2** Query Parameters

   +---------------+-----------+---------+-----------------------------------------------------------------------------------------------------+
   | Parameter     | Mandatory | Type    | Description                                                                                         |
   +===============+===========+=========+=====================================================================================================+
   | limit         | No        | Integer | Number of items displayed on each page                                                              |
   +---------------+-----------+---------+-----------------------------------------------------------------------------------------------------+
   | offset        | No        | Integer | Offset, which is the position where the query starts. The value must be greater than or equal to 0. |
   +---------------+-----------+---------+-----------------------------------------------------------------------------------------------------+
   | secrecy_level | No        | String  | Security level.                                                                                     |
   +---------------+-----------+---------+-----------------------------------------------------------------------------------------------------+
   | name          | No        | String  | Indicates the rule name.                                                                            |
   +---------------+-----------+---------+-----------------------------------------------------------------------------------------------------+
   | creator       | No        | String  | Rule creator.                                                                                       |
   +---------------+-----------+---------+-----------------------------------------------------------------------------------------------------+
   | enable        | No        | Boolean | Indicates whether the rule is enabled.                                                              |
   +---------------+-----------+---------+-----------------------------------------------------------------------------------------------------+
   | start_time    | No        | Long    | Indicates the start date.                                                                           |
   +---------------+-----------+---------+-----------------------------------------------------------------------------------------------------+
   | end_time      | No        | Long    | Indicates the end date.                                                                             |
   +---------------+-----------+---------+-----------------------------------------------------------------------------------------------------+
   | desc          | No        | Boolean | Sorting rule                                                                                        |
   +---------------+-----------+---------+-----------------------------------------------------------------------------------------------------+
   | order_by      | No        | String  | Sorting field. The value is createdAt, createdBy, updatedAt, updatedBy, name, description.          |
   +---------------+-----------+---------+-----------------------------------------------------------------------------------------------------+

   +--------------+-----------+--------+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

   | X-Auth-Token | Yes       | String | IAM token, which is obtained by calling the IAM API for obtaining a user token (value of X-Subject-Token in the response header). This parameter is mandatory for token authentication. |
