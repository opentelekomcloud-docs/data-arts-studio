Querying Technical Assets
=========================

Function
--------

Query technology assets.

Calling Method
--------------

For details, see :ref:`Calling APIs <making_request>`.

URI
---

POST /v3/{project_id}/asset/entities/search

.. table:: **Table 1** Path Parameters

   +------------+-----------+--------+-------------------------------------------------------------------------------------------------------------+
   | Parameter  | Mandatory | Type   | Description                                                                                                 |
   +============+===========+========+=============================================================================================================+
   | project_id | Yes       | String | Project ID. For details about how to obtain it, see :ref:`Project ID and Account ID <projectid_accountid>`. |
   +------------+-----------+--------+-------------------------------------------------------------------------------------------------------------+

Example Requests
----------------

     "search_all_attributes" : true,
     "offset" : 0,
     "limit" : 10,
     "type_names" : [ "Database" ],
     "query" : "cbu_training"
   }
